El proyecto está dividido en 7 bloques/carpetas:
•	1_Estandarizacion
•	2_Nulos_y_VariablesIrrelevantes
•	3_Repetidos
•	4_Outliers
•	5_KDD_Correlacion_y_seleccionVariables
•	6_Modelos_SinVarsGeo
•	7_Modelos_ConVarsGeo


En cada carpeta (proceso del desarrollo) se encuentran los programas Python en formato cuaderno (ipynb) donde se pueden ir reproduciendo los pasos de uno en uno.
En cada una de estas, también se encuentran los datasets necesarios para la reproducibilidad del proyecto. 
Además, pueden encontrarse subcarpetas donde se alojan procesos extras que se tuvieron que emplear como por ejemplo 
la creación de mapas o el cálculo de distancia al centro en el caso de la carpeta “7_Modelos_ConVarsGeo”.


Quizás la única dificultad se encuentra en la carpeta “1_Estandarizacion”, ya que tiene 3 cuadernos distintos, pero vienen ordenados para que se pueda reproducir sin problema.
